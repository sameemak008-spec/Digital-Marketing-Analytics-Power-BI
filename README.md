# Marketing Analytics — Power BI

## Project Overview

This project analyzes digital marketing and user behavior data to evaluate campaign performance, audience characteristics, traffic acquisition, user acquisition, landing page performance, events, conversions, and sales.

The goal is to identify high-performing channels, understand user behavior, and generate actionable marketing insights.

## Objectives

- Analyze marketing campaign performance
- Understand audience demographics
- Evaluate traffic acquisition channels
- Analyze user acquisition
- Measure landing page performance
- Analyze user events and conversions
- Identify opportunities to improve marketing performance

## Dataset

The project contains multiple datasets:

- Audience
- Demographic Details
- Events
- Landing Page
- Traffic Acquisition
- User Acquisition

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel

## Analysis Performed

### Audience Analysis

Analyzed user demographics and audience characteristics.

### Traffic Acquisition

Compared traffic sources and acquisition channels.

### User Acquisition

Analyzed how users were acquired across different channels.

### Landing Page Analysis

Evaluated landing page performance and user behavior.

### Event Analysis

Analyzed user interactions and conversion-related events.
